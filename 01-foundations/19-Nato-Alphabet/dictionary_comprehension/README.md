# 📘 Dictionary Comprehension Exercises

A small collection of Python exercises focused on creating, transforming, and filtering dictionaries using concise dictionary comprehensions.

## Concepts practiced

* Creating dictionaries from lists
* Filtering dictionary entries with conditions
* Iterating over keys and values with `.items()`
* Calculating word lengths
* Converting temperatures from Celsius to Fahrenheit
* Generating random values

## Files

* `exercises.py` — Contains the exercises.

## Run

```bash
python exercises.py
```
