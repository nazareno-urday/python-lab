# 🧩 List Comprehension Exercises

A small collection of Python exercises focused on creating, transforming, and filtering lists using concise list comprehensions.

## Concepts practiced

* Transforming list elements
* Filtering values with conditions
* Converting strings into integers
* Reading data from text files
* Finding values shared by two lists

## Files

* `exercises.py` — Contains the exercises.
* `file1.txt` and `file2.txt` — Number sets used in the file comparison exercise.

## Run

```bash
python exercises.py
```
