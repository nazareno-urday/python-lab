# 🚨 Alert Stream

A small Python project to practice **iterators and generators**.

The program stores sample alerts and uses a generator with `yield` to deliver only those marked `ERROR`. Each alert has a defined structure using `TypedDict`.

## ✨ What I practiced

- Retrieving values one at a time with `iter()` and `next()`.
- Filtering alerts with a generator.
- Using a `for` loop to consume the generator.
- Adding type hints with `TypedDict`.

## ▶️ Run

Run the Python script. It uses sample data and needs no external packages.
