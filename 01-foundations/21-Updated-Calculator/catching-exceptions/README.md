# ⚠️ Exception Handling Exercises

A collection of small Python exercises focused on handling runtime errors and invalid data.

## Concepts practiced

* `try`, `except`, `else`, and `finally`
* `FileNotFoundError`, `KeyError`, and `IndexError`
* Creating custom exceptions with `raise`
* Reading, writing, and closing files
* Handling missing values in dictionaries

## Exercises

The file includes:

* Creating a missing text file.
* Validating human height before calculating BMI.
* Handling invalid list indexes.
* Counting likes when some dictionary keys are missing.

## Run

```bash
python exercises.py
```
