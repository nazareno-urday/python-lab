## 📖 Overview

This section documents my progression through the foundations of Python programming.

It contains practical exercises and increasingly complex projects designed to develop more than syntax knowledge. The main objective is to understand how programs are structured, how problems are divided into smaller steps, and how individual concepts work together inside complete applications.

Each project represents a specific stage of that progression—from basic terminal programs to modular, interactive applications.

## 🧠 Core areas

| Area                            | Concepts                                                                  |
| ------------------------------- | ------------------------------------------------------------------------- |
| **Python fundamentals**         | Variables, data types, operators, type conversion, and user input         |
| **Control flow**                | Conditional statements, loops, logical operators, and program state       |
| **Functions**                   | Parameters, arguments, return values, scope, and reusable behavior        |
| **Data structures**             | Lists, dictionaries, tuples, nesting, and data manipulation               |
| **Problem solving**             | Decomposition, pattern recognition, validation, and algorithmic thinking  |
| **Object-oriented programming** | Classes, objects, attributes, methods, inheritance, and composition       |

| **File handling**               | Reading, processing, and generating structured data                       |
| **Graphical applications**      | Turtle graphics, events, coordinates, movement, and collision detection   |
| **Code quality**                | Debugging, naming, readability, organization, and progressive refactoring |

## 🚀 Learning progression

### 1. Programming essentials

The first projects establish the fundamental building blocks of Python:

* Storing and transforming data.
* Receiving and validating user input.
* Controlling program behavior with conditions.
* Repeating operations with loops.
* Creating reusable functions.

### 2. Structured problem solving

The next stage focuses on converting larger problems into manageable components:

* Breaking requirements into smaller tasks.
* Selecting appropriate data structures.
* Tracking changing program state.
* Avoiding duplicated logic.
* Improving solutions through refactoring.

### 3. Object-oriented design

Projects gradually introduce object-oriented programming to create more organized and scalable applications:

* Modeling behavior with classes and objects.
* Separating responsibilities between components.
* Managing interactions between multiple objects.
* Using inheritance and composition where appropriate.
* Organizing programs across multiple Python files.

### 4. Interactive applications

Later projects combine previous concepts inside graphical and event-driven programs:

* Keyboard and mouse events.
* Coordinate systems and movement.
* Timed game loops.
* Random behavior.
* Collision detection.
* Score and state management.
* Reading and writing external data.

## 🛠️ Development approach

Every exercise is completed through active problem solving.

The purpose is not simply to reproduce finished applications, but to understand the reasoning behind each solution:

1. Identify the expected behavior.
2. Divide the problem into smaller responsibilities.
3. Build a simple working version.
4. Test individual parts of the program.
5. Detect errors and incorrect assumptions.
6. Refactor the solution for clarity and reuse.
7. Document the concepts demonstrated by the project.

This approach creates a visible progression from basic Python syntax toward cleaner, modular, and more independent software development.

## 📂 Repository philosophy

Each project is maintained as an individual learning artifact and includes, whenever appropriate:

* A clear project description.
* The concepts being practiced.
* Instructions for running the program.
* An explanation of its internal logic.
* Possible improvements and future extensions.

The goal of this section is to demonstrate not only what was built, but also the programming knowledge developed while building it.

## 🎯 Learning outcomes

Through these projects, I am developing the ability to:

* Translate ideas into working programs.
* Reason about program flow and changing state.
* Choose suitable structures for storing data.
* Design reusable functions and classes.
* Debug problems systematically.
* Read and process external information.
* Build interactive applications.
* Organize code into understandable components.
* Explain the decisions behind an implementation.
* Approach unfamiliar programming problems with greater independence.
