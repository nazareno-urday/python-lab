# 🧰 `*args` and `**kwargs` Exercises

A small collection of Python exercises created to understand flexible function arguments using `*args` and `**kwargs`.

## Concepts practiced

* Accepting multiple positional arguments with `*args`
* Processing keyword arguments with `**kwargs`
* Passing configuration values into functions
* Using keyword arguments to initialize class attributes
* Creating and working with Python objects

## Exercises

* Add an unlimited number of values.
* Perform a calculation using named arguments.
* Create a `Car` object using keyword arguments.

## Run

```bash
python exercises.py
```
